## 📖 О проекте

**CryptoBot-RL** – это исследовательский проект, сочетающий передовые методы обучения с подкреплением и глубокого обучения для создания торгового агента на крипторынке. В основе лежат:

- **Сбор данных** – гибкий парсер для Binance/KuCoin с расчётом технических индикаторов.
- **Торговая среда** – мультитаймфреймовое окружение на базе `gymnasium` с богатым пространством наблюдений.
- **Интеллектуальный агент** – архитектура PPO, усиленная **Transformer-блоком**, **Mixture of Experts (MoE)** и **внешней дифференцируемой памятью**.

Проект задумывался как личный бот, но сейчас служит экспериментальной платформой для отработки сложных RL-подходов на финансовых данных. Все компоненты работают, даже если полноценное обучение пока не завершено.

## ✨ Ключевые возможности

### 🧹 Парсер данных
- Загрузка OHLCV-свечей с Binance и KuCoin (любые пары, не только BTC).
- Расчёт более 6 технических индикаторов: RSI, ADX, Bollinger Bands, ATR, OBV и др.
- Сохранение в форматах Parquet / Feather для быстрого доступа.

### 📈 Торговая среда
- Поддержка трёх таймфреймов одновременно: `15m`, `4h`, `1w`.
- Окна наблюдения: 150, 99 и 19 свечей соответственно.
- Глобальные признаки: временные метки, текущий PnL, one-hot последнего действия.
- Гибкость: работа как с локальными `.parquet`, так и с потоковой загрузкой через парсер.

### 🧠 Архитектура агента
- **PPO** (Proximal Policy Optimization) как основной алгоритм.
- **RMSNorm** – стабильная нормализация без потери качества.
- **Transformer** с Multi-Head Attention.
- **Mixture of Experts (MoE)** внутри Feed-Forward слоя.
- **Внешняя дифференцируемая память** с операциями чтения/записи и механизмом забывания (на основе возраста и важности).

### 🔧 Модульность
Все компоненты вынесены в отдельные файлы – вы можете легко заменять датасеты, модифицировать среду или экспериментировать с архитектурой агента без нарушения целостности проекта.

```

│

├── 📓 Jupyter-ноутбуки
│   ├── model copy 7_3.ipynb   # ⭐ Главный ноутбук для обучения агента

│   ├── Transformer_blok.ipynb # Отдельный трансформерный блок (MHA + MoE)
│   ├── env.ipynb              # Визуализация и проверка среды
│   ├── env_test.ipynb         # Дополнительные тесты среды
│   ├── parse_data.ipynb       # Запуск парсера (вариант 1)

│
├── 📦 Прочее
│   ├── version.txt          # Все зависимости с точными версиями (Python 3.12)
```

> ⚠️ **Важно:** в файлах `parser_data.py` и `birja*.py` жёстко прописаны пути к данным (например, `D:\Python1\AI\cripto_bot\...`). **Обязательно замените их на свои директории** перед запуском.

## ⚙️ Установка и настройка

### 1. Клонирование
```bash
git clone https://github.com/nikit172/crypto-bot-rl.git
cd crypto-bot-rl
```

### 2. Виртуальное окружение (рекомендуется)
```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
# или
venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей
Все версии пакетов указаны в `version.txt`. Установите их одной командой:
```bash
pip install -r version.txt
```

Если файл не работает как `requirements.txt`, переименуйте его или установите вручную ключевые библиотеки:
```bash
pip install tensorflow==2.18.1 keras==3.10.0 numpy==1.26.4 gymnasium pandas ccxt ta pyarrow feather-format jupyter
```

**Требования:**
- **Python 3.12** – строго.
- **TensorFlow 2.18.1, Keras 3.10.0, NumPy** – строго, остальное может быть новее.

## 📊 Подготовка данных

Данные можно получить двумя способами:

### А. Запустить парсер из ноутбука
1. Откройте `parser.ipynb` или `parse_data.ipynb`.
2. Выполните ячейки. Парсер загрузит свечи, рассчитает индикаторы и сохранит `.parquet` в указанную папку.
3. Пример вызова в коде:
   ```python
   from parser_data import parse
   parse(symbol='BTC/USDT', timeframe='15m', limit=1000)
   ```
4. Повторите для трёх таймфреймов: `15m`, `4h`, `1w`.

### Б. Использовать готовые данные (только для BTC)
Если вы не хотите парсить самостоятельно, вы можете запросить у автора готовые Parquet-файлы для BTC (через Issues). В будущем планируется добавить пример данных в репозиторий.

## 🚀 Запуск обучения

Основной ноутбук – **`model copy 7_3.ipynb`**. Шаги:

1. Убедитесь, что пути к данным в `birja1.py` (или `birja2.py`) указывают на ваши Parquet-файлы.
2. Откройте ноутбук в Jupyter и выполните ячейки по порядку.
3. В процессе обучения модели будут сохраняться (путь указывается внутри ноутбука).

**Если среда не регистрируется в `gymnasium`** – не беда, вы всегда можете использовать её как обычный Python-класс, импортировав `TradingEnv` из `birja*.py`.

## 🧪 Текущее состояние и ограничения

| ✅ Работает | ❌ Требует доработки |
|-------------|----------------------|
| Парсер (любые пары, любые таймфреймы) | Полноценное обучение (проблемы с градиентами, большой `log_count`) |
| Торговая среда (мультитаймфрейм, индикаторы, действия) | Отсутствие предобученных весов |
| Архитектура агента (PPO, Transformer, MoE, память) | Регистрация среды в `gymnasium` может выдавать ошибки (но класс работает) |
| Внешняя память (чтение/запись, забывание) | Проект не завершён, используется как исследовательский стенд |

Проект остаётся **экспериментальным**, но предоставляет готовый инструментарий для собственных наработок. Если вы хотите помочь довести обучение до ума – открывайте Issue или Pull Request!
